# AGENTS.md

Graviton is a Windows-only Wails v2 desktop app: a Go backend plus a React 19/Vite frontend for Antigravity account switching and quota monitoring. It intentionally contains no reverse-proxy functionality.

## Commands

Run from the repo root unless noted.

- `wails dev` — full app with Go backend, Vite HMR, and automatic binding regeneration. Use this rather than `pnpm dev` alone, which cannot exercise the Go bridge.
- `cd frontend && pnpm build` — the only frontend verification (`tsc && vite build`). There is no frontend linter or unit-test suite.
- `go test ./...` — all Go tests. Single test: `go test ./internal/quota -run TestName -v`.
- Clean-checkout order matters: `cd frontend && pnpm install && pnpm build`, then `go test ./...` or `wails build`. The root package embeds `all:frontend/dist`, so `go test ./...` fails when `frontend/dist` is absent.
- `wails build` — builds the GUI binary. Plain `go build` is not the supported app build.
- `.\scripts\release.ps1 -Version 0.1.0-rc.1 -NoGit` — local release build; requires Wails CLI and NSIS on `PATH`. Also supports `-SyncOnly` (version/changelog sync only), `-DryRun`, and `-SkipTests`.

## Architecture

- `app.go` is the Wails-bound facade (window, tray, widget, auto-refresh); `app_env.go` adds environment/project/process bindings; `app_version.go` embeds `VERSION` and `changelog.json`. Every exported `App` method becomes a frontend binding.
- `internal/appservice` orchestrates account capture, OAuth import, quota refresh, switching, and deletion. Its global operation lock returns `AppError{Code: "BUSY"}` for overlapping operations; do not bypass it for state writes.
- `internal/cred` = Windows Credential Manager; `internal/storage` = TOML state under `%LOCALAPPDATA%\Graviton` (with legacy migration from `%LOCALAPPDATA%\CodeTool`); `internal/client` = Antigravity process and legacy SQLite switching; `internal/oauth` and `internal/quota` = Google OAuth and quota endpoints; `internal/envmgr` = project scanning, shell runners, managed processes, AI command suggestions; `internal/widget` = loopback IPC.
- The floating widget is a second instance of the same executable launched with `--widget --port=<port> --token=<token>`. Main and widget communicate over authenticated loopback HTTP/SSE (`internal/widget/ipc.go`); keep `main.go` argument handling and `IsWidgetMode` in sync.
- Frontend flow: `main.tsx` selects `WidgetApp` or `App` via `IsWidgetMode`; `App.tsx` uses `HashRouter` with `/quota`, `/env`, and `/settings`; all Go calls go through `frontend/src/services/api.ts`; UI state lives in Zustand stores; backend push updates use Wails events.

## Binding contract

- `frontend/wailsjs/` is generated but tracked in Git. After changing exported `App` methods or their Go types, run `wails generate module` (or `wails dev`/`wails build`), commit the regenerated files, then update `frontend/src/services/api.ts` and `frontend/src/types/index.ts`. Never hand-edit `frontend/wailsjs/**`.
- Go errors surface as `[CODE] message`; `api.ts` parses that into `{ code, message }`. Preserve error codes (for example `BUSY`) and the Simplified Chinese user-facing messages.
- Credentials must stay in Windows Credential Manager. Never write tokens/API keys to TOML or expose them through bindings; `AccountDisplay` is the sanitized projection.

## Versioning and release

- `VERSION` is the single source of truth. `changelog.json` is the changelog source; `CHANGELOG.md` is generated by `release.ps1` and must not be edited manually.
- Add a `changelog.json` entry for the target version before releasing; the script fails otherwise. Supported formats are `X.Y.Z` and `X.Y.Z-rc.N`.
- `release.ps1` syncs `wails.json` (numeric `X.Y.Z` only), `frontend/package.json`, its `.md5`, and the NSIS version. Do not hand-edit those version fields.
- Full release mode (without `-NoGit`) requires a clean tree except for release metadata files, refuses an existing tag, then builds, commits metadata, and creates tag `v<version>` without pushing. Pushing the tag triggers `.github/workflows/release.yml`, which rejects a tag that does not match `VERSION`.
- CI (`.github/workflows/ci.yml`) runs on `master`: `pnpm install --frozen-lockfile`, `pnpm build`, then `go test -v ./...`.
- `dist/` and `build/bin/` are ignored build outputs.

## Testing quirks

- Tests are Windows-specific (`//go:build windows`, Win32 APIs); there is no meaningful non-Windows test path.
- `internal/cred` tests write and delete a real entry in Windows Credential Manager (`Graviton/Antigravity/test-unit-account-123`). Avoid them where the local credential store must not be touched.
- `internal/envmgr` tests spawn real `cmd`, PowerShell, and Git Bash processes; the Git Bash test skips when Git Bash is absent. Managed-command tests allow up to 15 seconds each.
- Use `newTestApp(t)` / `t.TempDir()` for app and storage tests; never point tests at the real `%LOCALAPPDATA%` state.

## Frontend conventions

- Tailwind CSS v4 via `@tailwindcss/vite`; theme tokens live in `frontend/src/style.css` under `@theme`, not in a `tailwind.config.js`.
- Dynamic multi-column grids (quota metrics, account cards, detail groups, etc.) must use `adaptiveGridCols` from `frontend/src/utils/layout.ts` so a single item always spans full width (`grid-cols-1`) and 2 items do not leave an empty 3rd column.
- Let layout explain instead of adding secondary descriptions, modal/page subtitles, or redundant count/status tags (e.g., "已连接 N 个账号" when the list sits right below); keep only genuinely stateful indicators (tier, active, forbidden, expired, errors).
- Segmented switchers whose options have clear icon semantics (theme, motion, reset-time format, card/table view) must be icon-only via `IconSegmentedControl` (`frontend/src/components/IconSegmentedControl.tsx`) with hover Radix Tooltips carrying concise labels and live details; keep short text only for proper-noun or text-only concepts (Shell names, 已用/剩余, model sort).
- Components follow shadcn/ui Nova plus Radix primitives, Lucide icons, `motion/react` animations that respect the reduced-motion setting, and Zustand stores.
- User-facing UI copy and error messages are Simplified Chinese; match the existing tone.
- No CGO: SQLite uses `modernc.org/sqlite`. Do not swap in a CGO-based driver.
